# 《Agent 在工作，人真的下班了吗？》

马克思主义自然辩证法 · 第四讲「马克思主义科技社会观」课程视频作业。项目采用理性分析型 Video Essay，讨论 Agent 使人可短暂发起、让机器持续执行工作后，节约的直接操作时间为何未必成为劳动者能够自主支配的自由时间。

- **目标时长：** 3 分 40 秒（允许 3～4 分钟）
- **当前状态：** 内容细化版待审核；大纲与脚本均未冻结
- **提交截止：** 2026-10-21 24:00

## 当前论证

> Agent 让人越来越容易从劳动的执行中抽身，却没有自动使人从持续扩大的劳动要求中抽身。

本片只追踪一条转化链：低成本启动与异步/并行执行，可能让个人主动扩展任务；新增产出再经由协作、计划、评价与竞争，成为新的正常要求。技术本身不决定结果，关键在于劳动如何组织、任务标准由谁制定、成果如何分享。
