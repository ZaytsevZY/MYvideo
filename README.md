## 制作原则

先完成并冻结内容大纲，再完成并冻结视频脚本；之后才确认画风、制作路线和技术栈，最后进行素材生成。每个生成镜头都必须记录完整提示词、模型与版本、参数、输入素材、输出文件及迭代关系，以保证多人分批制作时可复现、可追溯且画风统一。
