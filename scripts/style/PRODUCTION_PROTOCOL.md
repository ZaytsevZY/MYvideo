# 制作、版本与留档协议

**版本：** PRODUCTION_PROTOCOL v0.3 · 2026-10-16
**当前版本入口：** [PROJECT_STATE](../PROJECT_STATE.md)。适用于本项目实际采用的动画代码、美术、声音、字幕、预览与最终渲染，不绑定代码生成模型。

## 版本与审核

1. 正文、分镜、风格、配音、时间轴与代码分别编号，每次制作绑定明确的一组版本。
2. 当前六章为工作稿，STYLE_BIBLE 为候选；内容审核、真实配音校时、分镜与风格确认后才作为正式制作输入。
3. 用户已明确后续流程不要求必须使用Claude；可直接编写或按需选用模型。当前01原生SVG／JavaScript逐帧导出可复用，Remotion为可选实现路线，实际框架与依赖如实登记，不因旧路线要求重新审批工具选择。
4. 文件名中的 `final`、历史“定稿”与自动生成的“已批准”声明不能替代审批依据。冻结须记录确认者、日期、依据和哈希。
5. 正文或风格发生实质变化时更新版本及依赖；后续场景不得混用旧声音、旧字幕或旧样式参数。

## 代码动画与声音记录

- 生成提示词逐字保存，包括本次实际提供的正文、全局约束、场景需求和后续修订；可保存为独立文件并记录路径与哈希，不能仅写关键词。
- 记录实际提供方、工具、模型标识与可见参数。用户计划模型不等于已完成的调用；无法确认的信息写明未知。
- Remotion、React、Node 等实际依赖、锁文件、字体、素材与渲染命令随工程保存。技能版本与运行时依赖版本分别记录。
- 分镜说明场景元素、时间变化和对应句子；代码动画不强制记录仅适用于扩散模型的种子、采样器等字段。
- 配音记录工具/配音者、准确声音标识、文本版本、语速设置、处理链、音频校验值与实测时长。
- 校验人的操作时间、机器执行时间与可支配时间在画面与口播中没有混淆。

## 逐次记录模板

记录写入 [GENERATION_LOG](../doc/GENERATION_LOG.md)。测试、预览与正式渲染应明确区分。

```text
记录 ID / 状态：测试、预览、候选、通过、淘汰
责任人 / 日期与时区：
正文 / 分镜 / 风格 / 配音 / 时间轴版本与文件哈希：
关联章 / 场景 / 句子 ID / 父尝试：
工具与准确模型标识 / 可见设置 / 未知参数：
输入文件、来源与哈希：
实际提交的完整提示词（或其完整文件路径与哈希）：
代码版本（提交号与未提交差异快照）/ 依赖锁 / 技能版本：
运行与渲染命令 / 分辨率 / fps / 编码与质量参数：
输出路径 / SHA-256 / 实测时长 / 音视频信息：
审核依据、发现的问题与采用结论：
下一步：
```

## 验收与归档

- 先检查论证与来源，再检查风格、文字可读性、声音及技术质量。
- 全片时长按实际媒体计算，含片头、结尾与参考文献页，满足课程 3～5 分钟要求。
- 导出时保存版本清单、渲染命令与最终文件校验值。
- 旧文件移至 `.tmp` 并保存原路径、用途、替代版本和哈希；原始历史记录不改写成新的审核结论。
- 无法找到的历史输出只记“未找到”，不补造文件、参数或复现成功声明。

## 章节连续性与技能入口

从[分章动画制作skill](../../skills/chapter-video-production/SKILL.md)继续02–06。镜头记录起止状态与邻镜关系；章间记录角色、任务ID／语义状态、画面锚点、机位轴线、局部时间与全片offset、字幕出入、转场帧归属。候选方案与实际接缝验证分开，邻章未制作不得记为已通过。声音仍按具体任务授权，无声样片不强制等待配音或追加音轨。
