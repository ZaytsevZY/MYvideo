# 创作边界与论证简报

## 已确认

- **片名：**《Agent 在工作，人真的下班了吗？》
- **核心问题：** Agent 使人可短暂发起、让机器持续执行工作后，为什么有时形成自由时间，有时转化为更多任务与新的生产要求？
- **中心判断：** Agent 让人越来越容易从劳动的执行中抽身，却没有自动使人从持续扩大的劳动要求中抽身。
- **贯穿情境：** 程序员睡前派发功能和测试，次日验收、修改，并在碎片时间重新启动任务。它是说明性场景，不是实测案例。
- **时长：** 3 分 40 秒；旁白工作预算约 820～920 字，以真实朗读校准。

## 唯一解释链

`低成本启动、异步/并行执行` → `个人可主动扩展任务` → `新增产出进入计划、评价与协作` → `组织可能重设正常工作量` → `可自主支配时间未必增加`。

这不是技术决定论。Agent 可以真实释放时间；结果取决于劳动如何组织、任务标准由谁制定、成果如何分享。

## 必须区分

- **人的直接操作时间：** 派发、检查、干预和亲自完成任务的时间。
- **机器执行/任务持续时间：** Agent 后台运行，不直接算作人的劳动时长。
- **可自主支配时间：** 不被期限、响应义务与新增任务持续侵入的生活和发展时间。
- **技术与组织：** 不将“社会必要劳动时间下降”直接等同于 KPI 上升；后者须经由计划、评价、竞争与管理机制解释。

## 理论、证据与边界

- 《政治经济学批判（1857—1858 年手稿）》：技术节约劳动的能力如何被转化为剩余劳动的矛盾。
- 《资本论》第一卷：生产力增长可被用于扩大生产，并非自动缩短工作日。
- 伯克利 Haas 的科技公司定性研究：支持分析主动扩展任务与期待重设；不外推为所有企业的因果定律。
- NBER 的生成式 AI 研究仅作对照背景，说明效率也可能兑现为时间节约。
- 不扩展就业总量、阶层重组、完整技术史、离线权制度、初级岗位或劳动异化四重结构。
- 不使用“AI 是双刃剑”“马克思预言了 Agent”或未经核验的口号和数据。

## 表达规则

理论前置并参与推导，使用短句和具体动词；承认兴趣、成就感与职业竞争可能是真实动机，不把自愿简单说成虚假。当前不做视觉设计、分镜、画风或正式镜头。
