# 旁白语速校准

版本：NARRATION_TIMING v0.1 · 2026-10-21

当前项目采用微软云扬`zh-CN-YunyangNeural`，`rate=-5%`、`pitch=-2Hz`。以下为本项目28个完整语句的实测，不代表微软所有声音或默认`rate=0%`的统一速度。本轮只读取本地录音，无新TTS请求。

## 采用值与计数

旧计划为220字符／分钟，单位不是每秒。后续本项目改用约**300非空白字符／分钟**，或约**260汉字／分钟**。两种计数不能混用：前者计入标点、英文字母和数字，后者只计汉字。Agent等英文的发音时间已经包含在样本中，英文比例明显变化时重新合成测时。

- 28段句子WAV：994个非空白字符／860个汉字，185.43秒，约321.6字符／分钟，或278.3汉字／分钟。保留句内自然停顿和短静音安全边，未把每个音素之间的静音剔除。
- 再计入正常句末和章末换气：200.97秒，约296.8字符／分钟，或256.8汉字／分钟。正常句间停顿为已采用的排时设置，因此这是用于编剧的排时口径，并非全部由微软模型自动产生。
- 章间实测排时范围约280–310字符／分钟。规划采用300，新增或大改稿仍需实际合成后逐句校时。

## 使用规则

预计口播流时长（秒）＝非空白字符数÷300×60。只有汉字统计时可暂用汉字数÷260×60；二者只选一种。上述速度已含正常句间停顿，不再额外重复添加同一换气时间。文献卡、明确需要的操作／读图和生活留白另外登记，不能把完整视频或280秒WAV里的长静音当成配音速度。

当前994字符用新规则约需198.8秒；样本含正常换气实测为200.97秒。v13全片候选223.73秒还含独立的片头接续、结尾生活留白与14秒文献页，不能拿994÷223.73替代自然口播语速。

原4分40秒和六章45／38／39／55／45／58秒预算保留。语速校准不授权缩短画面或改写人工口播。此前约262汉字的补稿估算只用语句音频速度；若新增段落也安排正常换气，按各章排时速度约需**240汉字**，是规划近似，取决于新增句数和英文比例；此前245–275字可作较紧凑叙述的范围。

旧《创作任务书》记录的1100字符上限作为独立约束保留，不因速度改为300而自动增至1500。当前994字符距该上限只剩106字符；如需按约240–260汉字扩稿并保持280秒，应先明确如何处理该既有上限。本轮只修订估算规则，不扩写正文。
