# 创作边界与交接说明

## 已确认

- 主题是 **Agent 时代人类劳动主体性的变迁与异化风险**，而非笼统讨论“AI 会不会取代人”。
- 重点是两层变化：
  1. 劳动实践：人是否仍能参与、理解、干预并控制劳动过程；
  2. 劳动者身份：技能稀缺性、职业入口、议价能力与实践机会如何变化。
- 视频使用理性、客观、辩证的分析语气；承认 Agent 的生产力价值，也讨论其在特定组织和生产关系下的风险。
- 目标时长为 3～4 分钟，历史部分只服务于 Agent 时代的分析。

## 不作为主线的内容

- “效率提高却更忙”和工作侵入私人生活只能作为辅助现象。
- 大规模失业、开源与垄断、社会一般智力、劳动意义等可作为资料候选，但不单列章节。
- 不写成“程序员被 AI 替代”的戏剧化短剧；真实案例只服务于论证。

## 理论与事实表达约束

- 自动化不等于劳动异化；直接参与劳动、实质控制劳动、通过实践形成能力是不同问题。
- Agent 的“监督者”岗位不天然等于拥有控制权；需判断其能否设定目标、理解过程、干预决定并承担合理责任。
- 劳动技能的市场稀缺性变化，不等于人的社会价值或尊严下降。
- 去技能化不是唯一趋势；Agent 也可能支持学习和能力增强。
- 需区分自主 Agent、一般生成式 AI 与 Copilot 式辅助工具；不能混用证据。
- 引用理论、研究或新闻时，先核验原始来源、版本、统计口径、发布日期和适用范围。
