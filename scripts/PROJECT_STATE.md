## 主题基准

- **工作片名：**《当效率成为义务》——Agent 时代的劳动悖论。沿用较新的 Claude 稿与交接记录；旧题《Agent 在工作，人真的下班了吗？》作为历史题目，不要求补回现稿。
- **课程方向：** 马克思主义科技社会观；围绕 Agent 对劳动过程、自主权与自由时间的影响展开解释型 Video Essay。
- **中心问题：** Agent 提高执行能力后，效率收益为何可能转化为新的生产要求，而未同步成为劳动者的自由时间与决定权？
- **当前工作文本：** [六章原口播与尾注 SHOT_TEXT v0.2](final/shot/README.md)。按用户要求逐字恢复核查前 `text`，保留 `subject`；引用与核查意见只列文末尾注，不在口播中插入引文或注号。
- **论证结构：** 开场情境 → 任务成本与任务范围 → 劳动关系与任务分配 → 竞争与标准变化 → 执行能力与决定权 → 效率收益的去向。

## 已确定的制作路线

- 用户已明确：完全由 Claude 编写动画代码，再渲染成片。使用 Remotion / React；本轮未创建动画工程或渲染视频。
- 用户计划采用 Claude Opus 5.5；实际使用的工具标识、模型标识、Remotion 依赖版本仍须在首次执行时记录，不能以计划代替调用记录。
- 分镜使用 `storyboard-prompt-assistant`；动画实现使用 Remotion 官方 skills。按代码动画描述画面与时间变化，不强制套用文生视频的正/负提示词或 2～6 秒镜头限制。
- 项目共用文件位于 `.claude/skills/`，Codex 通过 `.agents/skills/` 中的链接发现相同的 8 个技能；第三方技能版本独立于影片版本。

## 时长与审核事实

- [课程原始要求](../COURSE.md)为成片 **3～5 分钟**；片尾与参考文献页也计入成片总长。
- 当前六章 `<start>` 与 `<end>` 之间正文共 **1,683 个汉字**，分章为 **238 / 264 / 235 / 352 / 250 / 344**。按 Unicode 汉字计数，排除英文、数字、标点、标题、尾注与空白。
- 沿用旧交接稿的 220～250 汉字/分钟假设，单汉字部分约 **6:44～7:39**，尚未计入英文读法及停顿。此为预算检查，不是实测音频时长。
- 原 3:40、820～920 字的预算与旧稿“约 1100 字、约 5:00”的统计不再有效。正式章节时长需讨论与试听校准；未经明确要求，不为时长预算自行压缩原口播。
- 旧交接稿曾写“已批准”，旧旁白曾写“定稿”，但也保留待人工审核项；这些标签不能单独作为当前版本通过审核的依据。
- 原稿中有关合同、裁员、机器雇主等问题按用户要求原样保留；16 条文末尾注指出其概念与证据边界。恢复原文不等于为其全部断言背书；新增文献短引文不进入 `text`。
