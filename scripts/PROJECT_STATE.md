## 字符与时间

- 用户的口播上限为5×220＝1,100字符。audio content合计 **840个非空白字符**（含标点、英文和数字），其中汉字752个；含各章段内空格换行共866字符，均在上限内。
- 每章非空白字符：155 / 121 / 127 / 171 / 156 / 110。只统计 `<start>` / `<end>` 间音频文本，视频描述、引用和元数据不进入配音。
- 暂定全片 **280秒（4:40）**；六章为45 / 38 / 39 / 55 / 45 / 58秒，最后14秒为纯画面文献卡。共21个画面段落。
- 时间为预算而非实测，保留读图和停顿空间；临时配音后逐句校准，不强行拉慢语速填满时段。
- 课程要求成片3～5分钟，含片尾；提交截止与原要求见 [COURSE](../COURSE.md)。

## 事实与引用

《资本论》为劳动概念的主要依据；《1844年手稿》的异化视角与《1857—1858年手稿》的时间讨论分别标注。研究卡仅对应Haas单一公司访谈材料，竞争传导图另标机制示意；不将其合并为已验证的普遍因果律。

16条尾注按audio段落和V段落ID定位。配音不读注号或出处；字幕从同一正文生成后添加脚注。两处画面短引文统一ASCII英文双引号，分别对应C6、C8；口播不直接引用长段落。
