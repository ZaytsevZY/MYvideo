## 音画分工

- `### audio content`：精简叙述，只承担主论证；不包含出处名称、解释性注号或逐项研究方法。配音仅提取 `<start>` / `<end>` 中的文本。
- `### video content`：各章画面段落承载情境、资源分配对照、研究样本、三层时间、任务标准变化及决策权限关系；以状态变化和补充信息服务论证，不把旁白全文再铺到画面上。
- 研究观察与理论应用在references和制作记录中区分；画内移除制作分类角标，必要资料脚注保留，不把情境演出冒充测量结果。
- 原稿的必然裁员、员工必然自费、机器成为雇主、成本等同价值等问题已修正或移除；无依据的断言也不迁入 video content。

## 字幕与引用

`references` 保留 16 条音画尾注，按 audio 段落和 Vxx.x 段落 ID 对应来源。配音不读注号；字幕使用同一口播文本，再按尾注映射加脚注。画面引用以各章当前分镜为准；05新版不另插独立引文页，06保留[C8](../../doc/SOURCES.md#c8)短引。直接引文统一使用ASCII英文双引号，不增加口播引用。
