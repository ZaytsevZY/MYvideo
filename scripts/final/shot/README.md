## 音画分工

- `### audio content`：精简叙述，只承担主论证；不包含出处名称、解释性注号或逐项研究方法。配音仅提取 `<start>` / `<end>` 中的文本。
- `### video content`：21 个画面段落承载情境、资源分配对照、研究样本、三层时间、任务标准变化及决策权限关系；以状态变化和补充信息服务论证，不把旁白全文再铺到画面上。
- 研究观察与机制推演在画面中采用不同的文字标识；假想场景、非数值图示与反事实方案均标为示意，不伪装成测量结果。
- 原稿的必然裁员、员工必然自费、机器成为雇主、成本等同价值等问题已修正或移除；无依据的断言也不迁入 video content。

## 字幕与引用

`references` 保留 16 条音画尾注，按 audio 段落和 Vxx.x 段落 ID 对应来源。配音不读注号；字幕使用同一口播文本，再按尾注映射加脚注。画面短引文仅有两处，统一使用 ASCII 英文双引号，分别对应 [C6](../../doc/SOURCES.md#c6)、[C8](../../doc/SOURCES.md#c8)，不增加口播引用。

完整来源与概念表见 [SOURCES](../../doc/SOURCES.md)，事实与分配检查见 [FACT_CHECK](../../doc/FACT_CHECK.md)。

## 制作衔接

画面段落为 Remotion 代码动画的文字需求；颜色、字体等沿用 [STYLE_BIBLE](../../style/STYLE_BIBLE.md) 的候选状态。`description` 与 `generation style` 仅指向统一入口，不维护另一套镜头或风格规则。

本轮按用户要求未在 `.tmp` 新建副本。早先归档仍属于历史记录，不作为当前音画稿输入。
