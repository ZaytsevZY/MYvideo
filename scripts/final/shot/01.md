## subject

劳动生产力提高与任务边界：Agent 减少直接执行，为什么未必让人更早结束工作？

## text
<start>
夜深了，一位程序员准备下班。

他没有继续熬夜修代码，而是给 Agent 下了几条指令，让它写代码、跑测试、整理结果。
然后关掉屏幕去睡觉，等待第二天早上验收任务。

Agent 确实给他的工作带来了很多便利。过去可能需要一整晚的工作，现在只需要一段指令和第二天的审核。

在公司的每周会议上，项目总管统计着生产力的提升，似乎每周都在向 AGI 更近一步。

他的 Todo-list 也在同步增长。既然开发这么方便，为什么不顺手再补几个测试、优化一下界面、把上周推掉的需求也排进来？无非就是多花一些token，多花一些时间，在餐桌上、在地铁上点点“确认”按钮...

Agent 就可以做完原来的工作。但他发现，"做完工作"似乎离他越来越远。
<end>
