# 制作与生成可复现协议

本协议适用于任何参与者、任何批次、任何模型生成的画面、视频、音频或代码。其目的不是限制创作，而是让每个镜头可追溯、可复做，并在多人分批制作时维持统一画风。

## 不可跳过的门禁

```text
内容大纲 v1.0 冻结
        ↓
视频脚本 v1.0 冻结（参考优秀案例的节奏、论证与镜头组织）
        ↓
分镜表与镜头编号冻结
        ↓
画风圣经与全局提示词块冻结
        ↓
生成参数、素材库与记录模板准备完成
        ↓
逐镜生成 / 渲染 / 审核 / 迭代
```

任何生成任务不得跳过前四项。若大纲、脚本或画风发生实质变更，必须创建新版本；后续镜头不得混用旧版与新版规则。

## 暂定技术选型

- 暂定核心创作模型：**Claude Opus 5.5**。
- 在首次实际调用前，记录提供方、准确模型标识、访问方式、版本/日期、用于内容/代码/提示词/素材生成的具体职责。
- 实际视频生成平台、渲染工具和后期工具尚未确定；不得把 Claude Opus 5.5 自动视为唯一的视频生成平台。

## 风格圣经（生成前必须冻结）

在 `scripts/STYLE_BIBLE.md` 中固定下列项目，并为其分配版本号：

- 成片画幅、分辨率、帧率、时长基准和交付编码；
- 整体艺术风格、情绪、色板、光线、材质、构图和镜头运动规则；
- 人物/空间/界面等反复出现元素的外观与命名；
- 字体、字幕、图表和转场规则；
- 禁止项（例如画面抖动、角色变形、现代素材混入历史段落等）；
- 固定的“全局风格提示词块”和“全局约束提示词块”。

每个镜头只可在“镜头变量块”中描述主体、动作、场景和镜头任务；组装后的完整提示词仍必须逐字记录。

## 逐镜生成记录

所有生成记录写入 `scripts/GENERATION_LOG.md`，一个镜头可有多次尝试。不得只保存“关键词”或事后概括的提示词。

````md
## [镜头编号]-[尝试编号]

- 状态：候选 / 通过 / 淘汰
- 责任人：
- 日期与时区：
- 大纲版本 / 脚本版本 / 分镜版本 / 风格圣经版本：
- 关联上一版本或父尝试：
- 生成目标：
- 工具与准确模型标识：
- 平台版本或页面/接口版本（如可见）：
- 输入素材：文件路径、来源、版本、哈希值；如使用参考图，附参考图编号
- 完整提示词：
  ```text
  此处逐字粘贴本次实际提交的全部提示词，包括全局风格块、镜头变量块、约束块及负面提示词。
  ```
- 完整参数：宽高/画幅、时长、帧率、种子、采样器、强度、生成数量、推理档位，以及平台可设置的全部字段
- 平台默认或不可见设置：已知内容；未知则明确标为“未知”
- 输出文件：路径、文件名、校验值、时长、分辨率、帧率
- 审核结论：与脚本和风格圣经的一致性、问题、是否可进入剪辑
- 下一步：保留 / 重试 / 需要重写分镜或风格规则
````

若平台不支持固定种子或导出全部参数，仍须记录该限制、完整提示词、生成时间、模型版本、输入文件和输出校验值。这样不能保证像素级复现，但可最大化过程复现。

## 提示词与素材管理规则

- 每次提交均保存**实际发送的完整提示词**；任何全局块更新后须重新保存完整拼接结果。
- 全局风格词、镜头变量词、负面约束词分段维护，但不能只引用版本号代替完整提示词。
- 输入参考图、音频、脚本和字幕均使用稳定文件名和版本号；修改后创建新版本，不覆盖历史记录。
- 每个输出文件绑定唯一镜头编号；淘汰结果也保留记录，防止重复试错。
- 任何人接手前先阅读最新冻结版本和生成日志；无记录素材不得进入正式剪辑。

## 审核门槛

- 先审核论证是否符合已冻结脚本，再审核画风与技术质量。
- 同一场景的候选镜头须与风格圣经逐项比对：色彩、人物/元素一致性、镜头运动、画幅、帧率、字幕安全区。
- 通过镜头进入剪辑后若需要重生成，保留原记录并以新尝试编号创建可追溯分支。
- 导出成片时，保留使用镜头清单、最终脚本版本、最终提示词日志版本和成片校验值。
