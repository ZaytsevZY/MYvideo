# 《Agent 在工作，人真的下班了吗？》

**版本：** 内容大纲 v0.9（待审核，非旁白稿）

**类型：** 马克思主义科技社会观 · 理性分析型 Video Essay
**时长：** 220 秒（3 分 40 秒）；旁白工作预算约 820～920 字

## 核心命题

**主问题：** Agent 使人可以短暂发起工作、让机器持续执行，为什么这项能力有时成为人的自由时间，有时又转化为更多任务和新的生产要求？

**中心判断：** Agent 让人越来越容易从劳动的执行中抽身，却没有自动使人从持续扩大的劳动要求中抽身。低成本启动与异步执行使个人可能扩展任务；新增产出经由协作、绩效、计划与竞争，可能成为新的正常工作量。

**贯穿情境：** 程序员夜间派发功能和测试，Agent 后台运行；次日验收、修改，吃饭时又顺手发起新需求。该情境仅用于说明，不冒充企业实测。

## 证据与使用边界

- **马克思，《政治经济学批判（1857—1858 年手稿）》：** 正式口播最多使用一条核验过的中文引文，解释自由时间与剩余劳动的张力；不可称马克思预言了 Agent。
- **马克思，《资本论》第一卷：** 作为机器、生产力与劳动强化的解释背景；不从任务完成量直接推算剩余价值。
- **Ranganathan 与 Ye，HBR / Berkeley Haas（2026）：** 主现实证据。约八个月、约 200 人美国科技公司民族志与四十余次访谈，观察到碎片时间使用 AI、并行任务与期望重设。它含生成式 AI 和部分 Agent 实践，不是所有企业的因果实验。
- **Dillon 等，NBER WP 33795（2025 修订）：** 仅作对照背景：在其特定实验条件下，生成式 AI 使用可减少邮件工作时间；不与 Haas 研究拼成历史阶段论。

## 明确不做

不讲全社会失业、阶层重组、完整技术史、离线权比较、劳动异化四重结构或“AI 有利有弊”。不将社会必要劳动时间直接等同于 KPI，不把后台机器时长算作人的劳动时长。

## 建议收束句

> Agent 让人有能力不必一直工作；真正的问题是，我们能否拥有停止工作的自由。
