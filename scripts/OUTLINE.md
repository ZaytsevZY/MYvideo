# 《当劳动不再需要劳动者》

## 定位

- **类型：** 马克思主义科技社会观·分析型视频（Video Essay）
- **预计时长：** 3 分 40 秒（目标区间 3～4 分钟）
- **核心问题：** 当 Agent 能够自主完成越来越多生产任务，人类是从劳动中获得了解放，还是正在失去作为劳动主体的地位？
- **核心观点：** Agent 是生产力发展的延续，也可能开启人机劳动关系的新阶段。它能够减轻重复劳动、扩展人的能力；但若人失去对劳动目标、过程和结果的实质控制，并长期退出实践、学习和创造，技术进步就可能削弱人的劳动主体性。

## 叙事与论证原则

- 采用理性分析和视频论文形式，不采用虚构人物短剧作为主线。
- 重点分析两条主线：劳动实践的变化，以及劳动者身份和经济地位的变化。
- 历史脉络只作为背景：工业机器 → 计算机 → Agent；不把短片写成技术史。
- 自动化不等于异化；“监督”也不等于拥有实质控制权。
- 不把一般性生成式 AI 的研究结果直接表述为自主 Agent 已经造成的确定事实。
- 所有正式引文、统计数据和案例均须在脚本冻结前核验原始来源、版本、口径与适用范围。

## 片尾判断（候选）

> 我们创造机器，是为了将人从劳动的束缚中解放出来，而不是将人从创造和决定劳动的过程中排除出去。
