## C1

**马克思：《资本论》第一卷，第一章“商品”，第 1 节。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/008.htm)

- 定位：论商品价值量、社会平均生产条件，以及劳动生产力改变单位商品劳动耗费的段落。
- 用途：区分使用价值、价值、社会必要劳动时间与劳动生产力；纠正将成本收益比当作价值定义的说法。

## C2

**马克思：《资本论》第一卷，第四章“货币转化为资本”，第 1、3 节。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/014.htm)

- 第 1 节用于资本的增殖目的；第 3 节用于劳动力的含义、一定期限的使用与劳动力价值。
- 不支持“购买整个劳动者”或“雇主拥有无限时段”的说法。

## C3

**马克思：《资本论》第一卷，第五章“劳动过程和价值增殖过程”，第 1 节。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/015.htm)

- 定位：劳动过程要素、劳动资料和劳动对象；以及资本家消费劳动力时的监督、劳动过程和产品关系。
- 用途：劳动与劳动力使用的区分、生产资料及劳动过程的控制；不据此推定任意软件的现代知识产权归属。

## C4

**马克思：《资本论》第一卷，第八章“工作日”，第 1 节及有关正常工作日的讨论。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/018.htm)

- 用途：工作日的身体与社会界限，以及限制工作日的社会斗争。
- 这是历史和政治经济学分析，不代替当代劳动法与具体合同的判断。

## C5

**马克思：《资本论》第一卷，第十章“相对剩余价值的概念”。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/020.htm)

- 定位：新生产方法使商品个别价值低于社会价值、方法普及及竞争的讨论；章末关于节约单位产品劳动与缩短工作日的区别。
- 用途：相对剩余价值、超额剩余价值与竞争；不能从单项 AI 任务用时直接测定这些量，也不等于自动降低工资。

## C6

**马克思：《资本论》第一卷，第十三章“机器和大工业”，第 4 节“工厂”。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/023.htm)

- 定位：劳动条件与工人关系颠倒，以及劳动资料在资本主义劳动过程中的支配作用。
- 用途：区分技术工具与其社会使用方式；将这一分析用于 Agent 是本片的当代应用，不是原文已论证 AI 的效果。

## C7

**马克思：《资本论》第一卷，第十七章“劳动力的价值或价格转化为工资”。**

[中文原文](https://www.marxists.org/chinese/marx-engels/23/028.htm)

- 用途：规范工资、劳动力价值与劳动的表述；有关经济学价值的区分不等于评判人的尊严或社会贡献。

## C8

## 核查用概念与专有名词

以下为核查依据与后续可采用的规范口径；尚未据此修改恢复后的口播原稿。

| 用语 | 核查口径 | 依据 / 限制 |
|---|---|---|
| 劳动 / 劳动力 | 劳动是能力的实际运用；劳动力是人所具有的体力与智力能力。Agent 不称为马克思意义上的人类劳动力 | C2、C3；工资形式见 C7 |
| 生产资料 / 劳动资料 | 生产资料包括劳动资料与劳动对象；取得工具调用权，不能直接推出企业所有权或劳动决策权变化 | C3；软件工具的当代应用须作说明 |
| 资本 | 指特定生产关系中的资本，而不是任何机器或订阅服务的别名 | C2、C8 |
| 劳动生产力 / 劳动生产率 | 在一定劳动耗费下生产使用价值的能力；叙述统一优先使用劳动生产力，数量比较须保持质量与任务口径一致 | C1、C5；不把基准模型分数当人的劳动生产率 |
| 价值 / 成本 / 收益 | 商品价值量与社会必要劳动时间相关；企业成本、价格、利润预期分别讨论 | C1、C7；不用劳动的相对价值概括三者 |
| 社会必要劳动时间 | 社会正常生产条件及平均熟练程度、强度下，生产某种使用价值所需的劳动时间 | C1；不是单个程序员用时，也不是 KPI 的同义词 |
| 必要劳动时间 / 剩余劳动时间 | 工作日中再生产劳动力价值的部分，与超出该部分的劳动时间 | C5；不等于固定任务用时 / 新增任务用时 |
| 相对剩余价值 / 超额剩余价值 | 前者由必要劳动时间缩短及工作日两部分比例相应变化产生；后者涉及个别价值低于社会价值时取得的额外部分 | C5；不能把任意任务节时套成前者，也不直接用交付件数测量 |
| 工作强化 / 劳动强度 | Haas 的工作强化含任务、时段与并行变化；它不自动等同于马克思意义上的单位时间劳动耗费增加 | H1；《资本论》第一卷第十三章第 3 节另论劳动强化 |
| 劳动异化 | 本片聚焦劳动活动及成果作为不由劳动者支配的外在力量这一问题 | P1 补充，C3、C6 支撑生产关系分析；不是完整四重结构讲解 |
| 可自主支配时间 | 本片指不被工作要求持续侵入、可用于生活与发展的时间，是说明性口径 | 不冒充严格等同 C8 的自由王国或 C5 的必要劳动 |
| 人工智能体（Agent） | 依目标与环境反馈安排步骤、调用工具的 AI 系统；后文统一写 Agent | T1；不泛称所有生成式 AI 为 Agent |
| 生成式 AI | 引述研究时保留其较宽的技术范围，仅在原文支持时具体称多智能体实践 | H1；不用 Agent 替换全部研究对象 |
| 待办清单、基础模型、词元（token）、通用人工智能（AGI） | 需要时建议采用这些名称；AGI 距离、基础模型发展与 token 费用描述仍按原稿保留，缺乏依据处在尾注标明 | 避免将广告语言或未核查的费用假设写成事实 |
