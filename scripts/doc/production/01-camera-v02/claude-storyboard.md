**连续性与制作注记**
1. T01 的身份贯穿全片：卡片编号、颜色与位置的逻辑保持一致；状态依次为「派发 → 执行中 → 已生成 → 部分验收 / 返工（T01-R）→ 已验收」。「已生成」不等于「已验收」，验收动作只能由程序员完成。
2. 视点只有三种：正面反打（N4+N5，仅用于 S01-01/02）、背面过肩或中全景（原有背景）、逻辑舞台正面。背面 PNG 不翻转、不旋转；人物只做整体变换与姿态替换，不拼接肢体，不做人物叠化。
3. 屏幕关闭即人工直接交互结束，此后 Agent 一直处于工作状态；夜到昼的过渡只叠化背景，程序员离开与返回的过程都通过切镜省略。
4. 逻辑舞台机位锁定：程序员在左（N3），Agent 在右，且位于背板与图示之前；文字为可编辑 SVG，不做模糊处理；每个信息点后至少留 1.5s 读停。
5. 新计划只能由程序员的光标选入，Agent 仅做指向呼应；画面中不出现比例、倍数或「空闲」之类的结论性标注。
6. 屏幕空间分层（不随镜头运动）：情境标签在左上，字幕居下且避开 T01 区域，脚注在右下；问句只以字幕呈现，不做全屏文字。新增素材为 N1–N5 共 5 项，其余均为复用。
