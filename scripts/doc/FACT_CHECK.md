# 音画分配稿核查

**版本：** FACT_CHECK v0.4 · 2026-10-15

**对象：** [SHOT_TEXT v0.4](../final/shot/README.md)。v0.4只扩展第01章引入并对齐画面与尾注，其余五章口播沿用v0.3；不新建 `.tmp` 副本。

## 事实与概念

| 章 | 口播处理 | 画面处理与证据边界 |
|---|---|---|
| 01 | 恢复夜间派发、次日验收与计划扩张的情境引入；更早离开电脑不等同于获得自由时间；不报效率倍数、费用或AGI距离 | 夜间执行、次日审核及清单变化明确为情境示意；不把后台运行算人的劳动 |
| 02 | 用开发成本和项目可行性解释任务扩展，区分单项耗时与总投入 | 项目筛选与收益分配为定性模型，成本不当作商品价值；不绘制虚构数据 |
| 03 | 限定以工时组织的情境，分开约定工时、响应要求和任务标准 | 计时/计件差异及工时边界交给图示；不暗示雇主可以占用全部生活时间 |
| 04 | 只将一个公司的田野观察归于研究；竞争与组织传导另作分析，保留条件性 | 样本和方法补充在证据卡，跨企业过程改用机制示意标识；删除必然裁员 |
| 05 | 区分执行能力与生产决定权，以活动受外在力量约束讨论异化 | 调用权限与决策层分别显示；不将机器画成雇主，不假定员工必然自费 |
| 06 | 用效率收益去向与劳动参与收束，不将任何任务节时直接等同自由 | 两种时间配置为方案示意；共同控制与工作日短引文有语境，不声称缩短工时足以消除全部异化 |

## 引用与字幕

16条音画尾注按audio段落及V段落ID定位。口播只含叙述、转述和作者分析，不插入书目、注号或长引文；字幕从同一文本生成后加相应脚注。

两个直接短引文仅在第05、06章画面与尾注出现，均使用ASCII英文双引号，分别依据C6、C8。其他哲学文本P1、G1分别标注，不能混称《资本论》原话。全部13个来源见 [SOURCES](SOURCES.md)。

核查使用此前已阅读的中文原文及研究者访谈；HBR仍只核对公开元数据，未读取受限全文；未核实纸本版次，故不补页码。未新增研究数据或声称完成独立复现。

## 信息分配与风格

口播保留任务扩展、劳动关系、竞争、异化与收益分配这条论证链。样本、方法、情境、权限图、时间带和分配对照由画面补充，未把原稿全部内容强行压入口播。无依据的旧断言直接移除，不伪装成视觉补充。

叙述面向有背景知识的观众，删去铺垫性提示、重复转折、出处播报和无信息短句；以开场问句与结尾判断形成首尾呼应。画面不复写整段旁白，不给未批准的画风新增参数。

## 字数与时间预算

- 音频共840个非空白字符，包含标点、英文及数字；若计入段内空格和换行，共866字符，均低于5×220＝1,100字符上限。
- 其中汉字752个；不能用仅计汉字的较小数冒充全部字符预算。
- 暂定全片280秒，其中14秒文献卡不口播；21个画面段落在各章内连续分配。
- 字符数和计划时段不代替实际朗读，须经临时配音校准；本轮未生成声音或视频。

当前检查包括章节结构、字符数、画面区间连续性、尾注对应、引号、原页短引文与本地链接；不以这些结构检查替代最终内容审核。
