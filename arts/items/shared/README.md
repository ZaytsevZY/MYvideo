# 跨章屏幕与通知

四种可编辑UI，每种保留SVG和同名PNG。文字、状态和几何底框以代码绘制；人物头像来自采用的PNG绘稿，不以SVG拼五官。

- `backlog-list-v01`／`backlog-open-v01`：1440×900，搁置需求列表与打开detail；feedback保持候选／待评估。
- `notification-task-v01`：720×240，负责人追加安排；示例任务S03-C，跨章复用时按章改任务身份。
- `notification-result-v01`：720×240，Agent结果待验收；可与03睡眠／醒来主画面并行。

由[build.mjs](../../static/story-assets-v01/build.mjs)重建。UI按屏幕开口映射，不贴在笔记本背盖；更多用法与来源见[故事素材入口](../../static/story-assets-v01/README.md)。
