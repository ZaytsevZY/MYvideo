## 本轮修正

雇佣关系以1792×900面板覆盖1920×1080画幅，雇主／雇员分居两侧，双向箭头只表达薪水与有限期劳动力使用权的交换；补充劳动力、期限与时段内组织工作的概念。关系来自《资本论》C2／C3的理论语境，不表达无限支配。结尾树图同样放大，主角会议报告仍在处理中，两位同事分别编写代码／核对资料；不把主角先前完成的任务改派给同事。

主角在左侧758×1080正面工位整幅绘稿中出现，脸／身体／手／桌／独立键盘同一视角，显示器位于镜外摄影机方向。Claude审核发现首轮笔记本边缘与手接触不清，已整幅返工。右侧1112×936企业聊天窗采用常规Teams界面层级、稳定中文排版；09:12至14:01记录登录校验、导出修复以及会议报告追加，文本可直接读出当天多轮工作。气泡按内容定宽，消息时间与前条气泡留间距。14:00发送完成、14:01追加报告、17:00截止分别明确，无独立时钟。侧看同事以视线预备、头部转向、邻桌反打、回到正面输入承接，侧看时聊天降亮度。

邻桌按实拍参考重绘为两张完整中景，人物、椅背、桌面、显示器同一机位。Claude指出首轮全身机位的桌脚／椅轮仍有深度歧义，已返工为共用连续桌面的中景：两人坐在桌后，手臂／键盘／纸页接触明确，座位、膝盖与地面自然出画；未在旧空桌上继续平移人物修补。不另叠假电脑界面／动效线掩盖透视。

新头像用imagegen补齐负责人五官；程序员与两位同事头像从新场景直接裁切，人物身份一致。图中标明“雇主（企业）／由负责人代表”，不将负责人职位直接等同于雇主。SVG只承担可编辑聊天文字、常规窗口边框及关系连线，不绘制人物／桌椅／道具或用于堆装饰。
