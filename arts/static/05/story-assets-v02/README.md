## 分层与代表构图

注册16项：6张新场景＋10项库存PNG（员工／同事／负责人／Agent头像、企业、纸页、日间办公室）。首尾关系图复用头像和企业原图，文字／调用线／规则反馈独立原生绘制。新演员、桌子和主要道具没有用SVG几何人或肢体拼接替代。

6组12个1920×1080关键构图：双侧关系3态、交付2态、等待2态、停顿／重新输入2态、宣传插入1态、目的与尺度2态。每态同时保存可编辑SVG与供检查的PNG；SVG引用原图相对路径，播放器实时按层合成，不以整张构图PNG平铺代替图层。交付／等待／宣传还保存raster-only对照。

白板“深度和Agent合作”、广告“把重复劳动交给AI干”使用独立中文层，标牌字体跟随实际墙面角度，宽景文字安全范围避开人物头部；插入镜头放大阅读。广告内人物印图复用Agent PNG头像，无真实品牌logo。背景物件在各宽景中始终在原位置，近景不在前景人物身上硬贴白板文字。员工确认“已验收”、Agent“请给我下一项指令。”与邻桌“等待新指令”分别为局部反馈层；检查页可关闭标语、反馈层并显示字幕安全区。

双侧图从第一态就同时显示员工→Agent与企业→雇员，主角在两图中是同一C-P，不增人数；调整提议由员工进入组织，状态为待讨论。末图共同成果经人的组织安排形成工作要求，员工仍能向Agent发出具体指令；“排期与收益配置”中标明待讨论的是调整提议，未假装全部目标都尚未设定。无画内E／L、来源ID、制作类别角标或解释性免责声明。
