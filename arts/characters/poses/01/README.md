# 01 · 完整角色姿态与补充关键帧

**版本：** S01_WHOLE_POSES v0.2 · 2026-10-15。当前21张1024×1536透明PNG，均由内置image_gen.imagegen生成，原始像素未编辑；准确底层模型标识未暴露。

程序员共11张：背面操作、收手中间位、收手、起身前倾、半起身、接近站直、站立、向左转身、跨步、经过位与后腿回收。初始背对观众，视线朝向屏幕。Agent共10张：待命、抬手中间位、伸手、抓握前、握住文件、收回文件、身前持有、低头查看、递出文件、指向图解。次要人物仍使用上级目录无五官设定，本镜头不新增其动作。

本轮补充12次生图：Agent七张、程序员五张。完整提示词、实际引用路径和原始输出路径逐项存入prompts；当前清单为 [manifest-v02.json](manifest-v02.json)，旧manifest-v01.json仅记录首批九姿态。所有PNG直接复制，保持alpha和源像素，源文件SHA-256已核对。

握持、查看、递出帧将一张无文字纸张直接绘入角色，保证手指自然盖住纸张边缘；纸面仅三条灰线，不承载事实或图表。转移中的纸张单独由代码绘制，接触时切换为完整握持姿态，同一逻辑文件ID为T01。图解标签和任务状态仍独立可编辑。

关键帧时间、脚底基线、源图高度及整身均匀缩放见 [keyframes.mjs](../../../actions/01/keyframes.mjs)。当前采用有限赛璐珞姿态与连续整身缓动，姿态切换仍是离散绘制，不能称作30fps全新逐帧人物动画。步态只有三张侧面图加转身，轮廓仍有少量漂移；见 [动作预览](../../../actions/01/README.md)。
