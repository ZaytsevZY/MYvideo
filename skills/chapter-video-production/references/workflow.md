# 制作流程与01复用入口

本文件是操作指南。01历史数据帮助定位，不作为其他章的固定指标。

## 剧本细化

从目标章audio content的 `<start>`／`<end>` 提取口播并分配句子ID；video content是细化依据，description不另生第二套正文。没有改口播的请求时保留文字、标点与英文；确需改写时同步正文、字幕、时间轴与来源。先明确相邻章边界，再深入内部镜头。

先按主画面职责划分故事场景E／逻辑展示L，参考 `scripts/final/shot/STORY_LOGIC_PLAN.md`。用餐、等候会议、夜间继续输入、组织交接等应由真实空间中的人物行动承担；在图表旁加装饰头像或工位小窗不算E；真实人物场景并行组、人物主画面＋通知／负责人行动小窗可为E，按叙述职责判断。先定并行结构再决定生图比例；三窗用独立竖幅，主反应配通知用横幅留空区。分别列E／L，再按叙事时序交织，并携带同一对象完成切入与返回。素材不足时先登记缺口，不据现有图解库存取消故事场景。

每个父段拆成可实现镜头，写入该章video content或其明确链接的唯一镜头表：

| 镜头ID／父段／E或L | 本章相对起止 | 口播／来源 | 起始状态 | 人物动作→对象变化 | 景别／角度／运动／焦点 | 文字／层序 | 终态→邻镜 | 素材缺口 |
|---|---|---|---|---|---|---|---|---|

一镜解释一个主要变化；切换视点给出新信息或动作重音。读图复杂时可以延长同一镜并组织内部动作，不按固定2–6秒硬切，也不复制01的12镜。storyboard辅助技能可用于细化，但其短镜建议不替代实际阅读需要。

逐镜检查“谁触发、什么改变、观众据何得知”。清单延长要有任务进入、人物反复看电脑等行动；人工／机器比较可用角色头像、文件、流向与状态表达，避免字幕旁放静态图解。

## 美术盘点与准备

先查 `arts/characters/README.md`、其 `poses/01/`、`portraits/01/`，以及 `arts/static/01/RASTER_REFINEMENT.md` 和当前bundle，定位采用版。工位v01已被v02替代；文件存在不等于已采用。

资源清单写用途／镜头、库存路径、复用或新建理由、机位／表情／动作阶段、目标显示尺寸、透明需求、图层职责与接触锚点，区分必须新增和可选润色。按缺口生图，不为每句话另造背景。

生成前查看采用的角色、背景、合成图，固定识别特征、线宽、色阶、光照与透视；提示词说明完整姿态、实际取景和留白。纸张／屏幕不烘焙中文与事实文字；头像表情使用完整画像。透明对象输出真实alpha，背景不透明。按可用imagegen技能操作。

保存完整prompt、引用路径、实际工具／可见模型参数、原始输出、实际尺寸／alpha／SHA-256和采用原因；未知型号不虚填。检查PNG签名、透明边缘、原生比例，浅深底和真实画幅都要查看。布局裁切不修改源图；确需编辑像素另存新版。主工位与小窗共用透视，校准手／键盘、躯干／椅背、屏幕内容／开口、纸张／持有手。

## 代表构图与动态演出

先组合本章风险最高的画面：新机位、手持道具、复杂图解、跨章接点。在1920×1080当前画幅检查前中后景、朝向、地面基线、遮挡、焦点、字幕安全区。数值接触正确仍需目视审阅，合格后扩为全段。

01分件绑定因人体连接与遮挡差而停用；当前以完整PNG姿态配整身均匀缩放表达动作。预备、接触、发力和收势用对应绘稿。持有绘稿内纸张与独立飞行纸张互斥；同一卡在图解与操作小窗中同时显示属于映射，不计两份任务。

以章内时间／帧号确定状态，顺播、倒拖、导出同帧一致。思考、动作线、点击、交接、表情与短时模糊由动作状态触发和停止，不能依赖未重置timer。暂停可读，任意拖动都有完整状态。

按实际内容定图解容器高度，复用暖白局部底框、色义与图层规则。人物行动服务派发、查看、审核、离席；图解移动服务关系变化；镜头移动服务视点变化，避免三者全程同速漂移。主要动作后留收势和读图时间。逻辑段小窗解释主图；故事段可按剧本安排并行场景或触发／反应小窗，维持明确主次，不强制改回顺序播放。

|---|---|---|
| camera-motion.mjs | 状态采样、机位、合成层序 | 12镜、45秒、事件时点、任务状态 |

## 字幕、时长与声音

字幕单源JSON字段为 `text,startMs,endMs,timestampMs,confidence`，同步生成SRT、VTT与烧录层；未实测字段为null。核对原文完整、断句、阅读时间、字幕避让及预览／导出一致。主画面标签不复写口播全文。

无配音时按镜头和语义暂排，不宣称转录或语音对齐。01字幕覆盖0–45秒；其他章可以有合理空档。06当前44–58秒为两张纯画面文献卡，不能用最后一句口播字幕填满14秒。区间采用左闭右开，片尾不显示不存在的后续句子。

01当前参数为白字44px、深色半透明局部底、底边约18px，固定屏幕空间；仅作起点，目标构图与播放器中仍需核对宽度、字号和遮挡。来源／脚注单独放置，不拼进配音正文或挡字幕。

只有声音任务明确后才选声音、录制、测量并对轴；调整镜头与全片offset，不通过拉慢语速硬填预算。无声请求不自动生成配音、音效、配乐或静音音轨。

## 导出与验证

建立明确章节配置：ID、duration、fps、画幅、素材与代码版本、字幕版本、音轨有无、输出新版本。非整数帧预算明确取整后实际时长并更新全片表。当前30fps预算：01=1350、02=1140、03=1170、04=1650、05=1350、06=1740，总8400帧／280秒；后续按实际调整。

原生路线以frame/fps采样SVG，逐帧栅格化为RGB，有序流入FFmpeg，限制并发与缓存；保留少量QA图，不必保存全量PNG。01采用sharp／librsvg、H.264 libx264 medium CRF18、yuv420p、faststart、`-an`。旧最终文件不覆盖，成功后再将部分输出改为最终名。

下列命令只用于01验证；不是其他章的通用生产命令。现有01已成功导出，不为应用本技能重复渲染：

```sh
node --test arts/actions/01/camera-motion.test.mjs arts/actions/01/captions/captions.test.mjs
ffprobe -v error -show_streams -show_format -of json arts/actions/01/exports/01-captioned-silent-v01.mp4
ffmpeg -v error -i arts/actions/01/exports/01-captioned-silent-v01.mp4 -map 0:v:0 -f null -
```

导出前检查时间覆盖、有限变换、资源引用、人物／道具互斥、人工验收与候选状态、字幕完整性。导出后核对帧数／时长／尺寸／帧率／音轨，全程解码，查看编码后的首中尾、风险动作与字幕切点。01原13项动作＋3项字幕测试只是参考，测试数量不代表新章已通过。

拼接前核对编码、time base、像素格式；仅流参数兼容时直接concat，否则统一编码。检查时间戳、黑帧和重复帧。有音轨后另查采样率／声道／接点，无声片保持无音轨。

保存媒体与字幕、布局／时间轴、输入输出哈希、命令／依赖／字体、验证证据与边界契约，更新日志和交接。01约10分钟编码仅为该轮本机实测，不作为后续工期。MP4现被gitignore排除，本机存在不等于进入版本库，交接提供可用绝对路径。
