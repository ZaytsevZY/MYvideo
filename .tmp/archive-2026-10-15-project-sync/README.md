## 恢复方式

1. 在 `manifest.json` 找到原路径与归档路径，按 SHA-256 核验文件。
2. 恢复前先保存当前同名文件，再将单个归档文件复制回其原路径；不批量覆盖当前工作。
3. 如需复做旧 demo，需把其代码、旧旁白和临时音频一并恢复到原相对路径；归档代码原样保留，内部仍可能包含旧路径。

归档中的历史 Markdown 链接与脚本路径有意保持原样，不适用于现行目录的链接检查。新旧版本不能直接混用于同一次渲染。
